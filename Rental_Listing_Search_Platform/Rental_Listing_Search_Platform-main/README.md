Rental Listing & Search Platform

提供房東刊登出租資訊與租客尋找房源的媒合平台，具備完整的會員帳密登入系統，並透過 SQL 關聯式資料庫進行用戶與房屋資料的建置與管理，打造安全且便捷的租屋平台。

Features

Secure user authentication (Login / Register)

Post, edit, and manage rental property listings

Search and filter available rentals

Detailed property views and contact information

Relational database management for users and listings

Tech Stack

Frontend: HTML / CSS / JavaScript

Backend: Python / PHP 

Database: MySQL
