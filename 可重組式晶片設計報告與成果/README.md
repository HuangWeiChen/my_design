# 可重組式晶片設計報告與成果

這裡整理以 FPGA 與硬體描述語言完成的四個練習：串列通訊、影像運算、卷積運算與迷宮路徑搜尋。各題包含設計檔、模擬或編譯相關檔案，以及獨立的實驗報告，便於對照規格、架構與結果。

| 題目 | 設計重點 | 報告 |
| --- | --- | --- |
| [RS-232](RS232/) | 8 位元資料的傳送與接收，包含完成訊號與模擬波形 | [接收器](RS-232%20Reciever_report.pdf)／[傳送器](RS-232%20Transmitter_report.pdf) |
| [TDI](TDI/) | 8×8 影像的 Time Delay Integration，串列資料接收、FIFO 暫存、累加與像素輸出 | [TDI 報告](TDI_report.pdf) |
| [Convolution](convolution/) | 8×8 影像與 3×3 濾波器的硬體卷積，結合 SPI 接收、暫存與乘加運算 | [卷積報告](convolution_report.pdf) |
| [Maze](Maze/) | 17×17 迷宮的地圖接收、死路處理與移動決策，目標為救出人質並抵達終點 | [迷宮報告](MAZE_solver_report.pdf) |

## 如何閱讀

建議先讀各題報告中的實驗規格與架構圖，再對照對應資料夾的 `design` 和 `simulation`。迷宮題另有[原有操作說明](Maze/README.md)，記錄測試模式、輸入檔及動畫程式的使用方式。

此目錄包含課程實驗與工具產生的專案檔；不同題目有各自的測試流程，請以相應報告及測試平台設定為準。
