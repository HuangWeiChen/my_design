# 超大型積體電路：Cell-Based IC 設計流程

這份期末報告記錄以 RISC-V 設計為基礎，執行 Cell-Based IC 設計流程的過程。內容從 RTL 功能模擬、邏輯合成與閘級模擬，延伸到自動布局繞線及實體設計檢查，展示從硬體描述到晶片實作結果的銜接。

## 報告內容

- `CHIP` 頂層與 I/O 接腳設定、RTL 模擬波形。
- 合成後的 timing report 與 netlist，以及閘級模擬結果。
- APR 階段的布局繞線與相關檢查截圖；最後整理實作心得。

完整圖表、設定與結果見 [超大型積體電路期末報告](超大型積體電路_期末報告.pdf)。報告提到以[計算機系統設計的 RISC-V](../計算機系統設計_RISC-V/)為基礎，並記錄整合接腳與流程設定時遇到的問題。

這個資料夾目前提供報告 PDF；若需重現實驗，還需要報告所述的設計原始檔、製程環境與 EDA 工具設定。
