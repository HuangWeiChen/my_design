# 6×6 黑白棋最佳落點搜尋

這個程式以 C++ 實作 6×6 黑白棋的落點搜尋。輸入棋盤、目前玩家與搜尋深度後，列舉合法落點，模擬八個方向的翻棋，透過 Minimax 搜尋選出評分最高的位置。

## 核心方法

- 以 `X`、`O`、`+` 分別表示兩方棋子與空格，檢查八個方向是否能夾住對手棋子。
- 對每個合法落點複製棋盤並翻棋，遞迴模擬雙方輪流下棋；一方無棋可下時跳過該回合。
- 搜尋終點以雙方棋子數差作為評分，最大化目前玩家的分數。相同評分保留依棋盤掃描順序先找到的位置。

## 編譯與輸入

```bash
g++ -std=c++11 -O2 Othello.cpp -o othello
./othello < input.txt
```

第一行是測資筆數 `n`。每筆測資依序輸入一個長度 36 的棋盤字串（逐列排列），再輸入玩家編號與搜尋深度；玩家 `1` 使用 `X`，玩家 `2` 使用 `O`。程式每筆測資輸出一組座標，列以 `A`–`F`、欄以 `a`–`f` 表示，例如 `Cc`。

> 目前程式預期每筆測資至少有一個合法落點；若無合法落點，主程式沒有定義對應的輸出。棋盤字串也應符合 36 個字元的輸入格式。
